# API 신청 가이드

주소 → 시/도 → 시군구 → 읍면동 → 지번(또는 단지명) → 동 → 호 → **공시가격**까지
드릴다운하는 화면을 만들기 위해 필요한 것들.

전부 **무료**다. 아래 1~4는 **자동승인**이라 신청하면 바로 키가 나온다.

---

## 왜 이 조합인가

시중 계산기는 부동산공시가격 알리미(realtyprice.kr) 데이터를 자체 서버에 미러링해서
같은 UX를 만든다. 그 경로는 Open API가 없고 저작권이 전면 유보돼 있어 감수해야 할 위험이 있다.

같은 화면을 **이용허락 제한 없는 공식 API만으로** 만들 수 있다.

```
[시/도·시군구·읍면동 드롭다운]  ← ① 법정동코드 API
        ↓
[지번 입력]  또는  [단지명 입력]  ← ③ 공동주택 기본정보 (단지명 → 주소)
        ↓
[동 선택] → [호 선택]           ← ② 건축HUB(지번) / ⑤ 상세주소API(도로명)
        ↓                           두 소스가 독립이라 교차검증한다
[공시가격]                       ← ② 건축HUB (여기에만 금액이 있다)
        ↓
[취득가·취득일 입력]  ← 사용자 입력이 정본. ④ 실거래가는 검증·참고용
        ↓
[조정대상지역 판정]   ← ①·⑤의 법정동코드 → 국토부 고시 이력 테이블
```

동·호를 얻는 경로가 둘(지번 기반 ②, 도로명 기반 ⑤)이라 서로 대조할 수 있다.
`juso.cross_check()`가 두 목록의 차이를 돌려준다 — 어긋나면 한쪽이 낡았다는 신호이므로
조용히 한쪽을 택하지 않고 사용자에게 확인을 요청한다.

## 1️⃣ 행정표준코드 법정동코드 — 주소 드롭다운

| | |
|---|---|
| 신청 | **https://www.data.go.kr/data/15077871/openapi.do** |
| 승인 | 개발·운영 **자동승인** |
| 이용허락 | 제한 없음 |
| 쓰는 곳 | 시/도 → 시군구 → 읍면동 드롭다운, 조정대상지역 판정 키 |

> ⚠️ 이걸 받으면 **화성시 동탄구 법정동코드**를 확정할 수 있다. 지금은 코드를 몰라
> 화성시 전체가 조정대상지역 '판정 불가'로 처리되고 있다.
> `getStanReginCdList`로 `locatadd_nm=화성` 조회 → 동탄구 5자리 코드를
> `rulesets/v2026.08.03/reference/regulated_areas.yaml`에 채우면 해결된다.

## 2️⃣ 건축HUB 건축물대장정보 — ★ 공시가격의 핵심

| | |
|---|---|
| 신청 | **https://www.data.go.kr/data/15134735/openapi.do** |
| 승인 | 개발·운영 **모두 자동승인** (심의 대기 없음) |
| 이용허락 | 제한 없음 |
| 쓰는 곳 | 동명·호명·전용면적·**주택가격(공시가격)**, 연도별 이력 |

두 오퍼레이션을 `mgmBldrgstPk`로 조인한다.
- `getBrExposPubuseAreaInfo` → `dongNm`, `hoNm`, `flrNo`, `area`
- `getBrHsprcInfo` → `crtnDay`(기준일), `hsprc`(주택가격)

**연도별 이력이 나오는 게 이 소스를 고른 이유 중 하나다.** 세부담상한 계산에
직전연도 공시가격이 필요한데, 다른 소스는 최신 스냅샷만 준다.

> 2026년 공시가격은 공시기준일 2026-01-01, **최종 공시 2026-04-30**이다.
> 따라서 `crtnDay=20260101` 데이터가 지금 조회돼야 정상이다. 안 나오면 반영 지연이므로
> 자동조회를 신뢰하면 안 된다.

## 3️⃣ 공동주택 기본 정보제공 서비스 — 단지명 검색

| | |
|---|---|
| 신청 | **https://www.data.go.kr/data/15058453/openapi.do** |
| 승인 | 개발·운영 **자동승인** |
| 이용허락 | 제한 없음 |
| 쓰는 곳 | "단지명 입력" 탭 — 단지명 → 주소(지번) 변환 |

`kaptCode`, `kaptName`, `kaptAddr`, `kaptDongCnt`(동 수), `kaptdaCnt`(세대 수) 제공.

> ⚠️ **공시가격은 없다.** 그리고 단지→동→호로 내려가는 오퍼레이션도 없다
> (`kaptDongCnt`는 동 '개수'라는 숫자일 뿐 목록이 아니다).
> 단지명을 주소로 바꾸는 용도로만 쓰고, 동·호는 ②에서 받는다.

## 4️⃣ 아파트 매매 실거래가 상세 — 취득가 검증·시세 참고

| | |
|---|---|
| 신청 | **https://www.data.go.kr/data/15126468/openapi.do** |
| 승인 | 자동승인 · 개발계정 10,000건/일 |
| 이용허락 | 제한 없음 |
| 쓰는 곳 | 사용자가 입력한 취득가가 그럴듯한지 검증, 시세 밴드 표시 |

> ⚠️ **호수는 절대 안 나온다.** 개인정보보호로 층 정보만 제공되고, 동은 소유권이전등기
> 완료 건에 한해 공개된다. 즉 "우리 집이 언제 얼마에 팔렸는지"를 자동으로 특정할 수 없다.
> 세법상 취득가액의 정본은 **매매계약서**다(소득세법 §97①1). 실거래가 공개시스템 값은
> 부동산거래신고법상 신고가액의 공개본이지 세법상 정본이 아니다.
> → **취득가·취득일은 사용자 입력이 정본**, 이 API는 검증 보조.

## 5️⃣ 상세주소 검색 API — 동·층·호 (승인 불필요)

| | |
|---|---|
| 신청 | **https://business.juso.go.kr** → 주소정보 자료제공 → 주소정보 API 연계 |
| 승인 | **신청 즉시 발급.** 개발승인키는 본인인증 절차도 없다 |
| 호출 | `https://business.juso.go.kr/addrlink/addrDetailApi.do` (공공데이터포털 아님) |
| 인증 | `confmKey` — 위 `DATA_GO_KR_KEY`와 **별개의 키**다 |
| 쓰는 곳 | 도로명주소 기반 동·층·호 목록 |

> 앞선 안내에서 "운영단계 심의승인"이라고 적었던 것은 잘못이다.
> 공식 활용가이드가 **"신청 즉시 이용 가능 · 1 시스템 1 승인키 부여"**라고 명시한다.

**요청**: `admCd`(행정구역코드 10 = 법정동코드), `rnMgtSn`(도로명코드 12), `udrtYn`(지하 0/1),
`buldMnnm`(건물본번), `buldSlno`(건물부번), `searchType`(`dong`|`floorho`), `dongNm`, `confmKey`
**응답**: `dongNm`, `floorNm`, `hoNm`, `admCd`, `rnMgtSn`

`admCd`가 곧 법정동코드라 **조정대상지역 판정에 바로 쓸 수 있다.**

> ⚠️ **승인키는 URL(또는 IP) 기준으로 부여된다.** 여러 도메인에서 같은 키를 쓰면
> 서비스가 중지될 수 있다. 로컬 개발용과 배포용을 따로 받아라.

> ⚠️ 가이드는 `bdMgtSn`(건물관리번호)을 필수 응답으로 적었지만 **실제 응답에는 없다.**
> 문서가 아니라 실응답을 기준으로 삼아야 한다.

### ⚠️ WAF 차단 — 반드시 지킬 것

가이드 §4.1이 경고하는 실제 사고다. 요청에 SQL 예약어나 특수문자가 섞이면
주소검색 서버가 SQL Injection으로 보고 **차단**한다. 한 번 차단되면 이후 정상 요청도 막힌다.

- 금지 단어: `or select insert delete update create drop exec union fetch declare truncate`
- 금지 문자: `< > = %`

`realestate_tax/sources/juso.py`의 `assert_safe()`가 **보내기 전에** 걸러낸다.
단어 경계로만 검사하므로 `Orchard빌라`·`Uniontown` 같은 정상 주소는 통과한다.

```powershell
$env:JUSO_CONFM_KEY = "발급받은 승인키"
```

가이드에 공개된 테스트 키 `TESTJUSOGOKR`로 샘플 조회가 되므로 신청 전에도 동작을 볼 수 있다.
(운영에 쓰면 안 된다.)

```powershell
python -m pytest tests/ -m live -q     # 테스트 키로 실제 호출 확인
```

## 키 설정

공공데이터포털은 서비스별로 키가 나오지 않고 **계정당 하나의 인증키**를 공유한다.
따라서 위 1~4를 전부 신청해도 키는 하나다.

```powershell
# 일회성
$env:DATA_GO_KR_KEY = "발급받은 인증키(Decoding 쪽)"

# 영구 (새 터미널에도 유지)
[Environment]::SetEnvironmentVariable("DATA_GO_KR_KEY", "발급키", "User")
```

> ⚠️ 포털이 **Encoding / Decoding 두 가지**를 보여준다. `%2B` 같은 게 섞인 쪽이 Encoding이다.
> 이 코드는 URL 인코딩을 직접 하므로 **Decoding 키**를 넣어야 한다.
> Encoding 키를 넣으면 이중 인코딩돼 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`가 뜬다.

⛔ 키를 코드나 커밋에 넣지 말 것. 환경변수로만 쓴다.

## 신청 후 순서

```powershell
# 1. 전체 키 점검 — 어느 API가 살아 있는지 한 번에 확인
python tools/check_apis.py

# 2. ★ 공시가격 실측 검증 — 다른 작업보다 먼저
python tools/verify_hub.py --dong 1168010100 --bun 1 --year 2026

# 3. 화성시 동탄구 코드 확정
python tools/check_apis.py --find-region 화성
```

2번이 가장 중요하다. `hsprc` 채움률이 낮거나 값이 알리미와 다르면 자동조회를
1차 경로로 쓸 수 없고, 사용자 직접 입력을 정본으로 유지해야 한다.
**검증 결과에 따라 설계가 갈리므로 이걸 먼저 돌려야 한다.**
