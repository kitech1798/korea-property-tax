# 배포 체크리스트 (사용자 수동 작업 2건)

코드는 배포돼 있다. 남은 것은 **키를 심는 것**뿐이다.
값은 이 파일에 적지 않는다 — 로컬 `.streamlit/secrets.toml`을 열어 그대로 복사한다
(이 파일은 `.gitignore` 대상이라 저장소에 올라가지 않는다).

## ① Streamlit Cloud 앱 생성

https://share.streamlit.io → **Create app** → *Deploy a public app from GitHub*

| 칸 | 넣을 값 |
|---|---|
| Repository | `kitech1798/korea-property-tax` |
| Branch | `main` |
| Main file path | `app.py` |
| App URL | `korea-property-tax` (이미 쓰이면 뒤에 `-app` 등을 붙이고 **최종 URL을 기억할 것**) |

**Advanced settings → Secrets** 에 `.streamlit/secrets.toml` 내용을 그대로 붙여넣는다.
두 줄이다 (`JUSO_CONFM_KEY`, `DATA_GO_KR_KEY`).

> Secrets를 나중에 고치려면 앱 화면 오른쪽 아래 **⋮ → Settings → Secrets**.
> 저장하면 앱이 자동으로 재시작한다.

### ⚠️ 함정 — 키 하나만 안 먹을 때 (실제로 당함, 2026-08-05)

PowerShell 5.1의 `-Encoding utf8`은 **BOM을 붙인다.** `secrets.toml`을 그렇게 만들면
첫 줄이 `﻿JUSO_CONFM_KEY`가 되고, TOML 파서는 BOM을 **키 이름의 일부**로 읽는다.
결과: **첫 번째 키만 조용히 사라지고 두 번째는 멀쩡하다.** "왜 하나만 안 되지"로 헤매게 된다.

한글 HTML·`.ps1`에는 BOM이 **필요**하지만 TOML·JSON에는 **치명적**이다. 파일 종류마다 반대다.
파이썬으로 쓰면 안전하다:

```python
pathlib.Path(".streamlit/secrets.toml").write_text(body, encoding="utf-8", newline="\n")
```

앱은 이제 이 상황을 스스로 알아채고 어긋난 이름을 그대로 보여준다(`app.py:_secret_near`).
경고가 뜨면 그 줄을 지우고 다시 입력하면 된다.

## ② juso 승인키를 배포 URL로 재등록

최초 승인키는 **집 IP 기준**으로 받았다. 도로명주소 API 승인키는 URL(또는 IP) 기준으로
부여되므로(가이드 3.1), 서비스 주소가 바뀌면 갱신해야 한다.

https://business.juso.go.kr → 로그인 → **주소정보 API 신청 내역**
→ 발급받은 **도로명주소 검색 API** 키 → *수정*
→ **서비스 URL**을 ①에서 정한 주소로 바꾼다. 예: `https://korea-property-tax.streamlit.app`

> 실측(2026-08-04): 등록 IP와 다른 IP에서도 호출은 됐다. 그러나 약관상 보장이 아니라
> **서비스가 중지될 수 있다**고 가이드가 명시한다. 동작하는 것과 허용된 것은 다르다.

## ③ 라이브 검증

배포 후 앱에서 직접 확인한다. 화면 밖에서 통과해도 화면에서 깨지는 일이 있다.

1. **② 물건 정보** 탭 → 주소 검색에 `압구정로 113` 입력
   → 후보가 뜨고, 고르면 동·호 목록이 나오고, 공시가격이 채워지는가
2. 키가 안 먹으면 화면이 **어느 키가 없는지** 이름을 대며 안내한다(`ui/address.py`).
   그 문구가 나오면 Secrets 이름 오타를 먼저 의심한다 — 값보다 이름이 자주 틀린다.
3. ③ 양도세 탭, ④ 상담 탭이 예외 없이 뜨는가

로컬에서 같은 경로를 먼저 확인하려면:

```
streamlit run app.py --server.port 8555
```

## 재배포

코드를 고친 뒤에는 스크립트가 게이트를 전부 통과시킨 뒤에만 푸시한다.

```
.\tools\deploy.ps1            # 테스트 · 룰셋 린트 · 시뮬레이션 125건 · 비밀 스캔
.\tools\deploy.ps1 -DryRun    # 게이트만 돌리고 푸시하지 않는다
```

Streamlit Cloud가 `main` 변경을 감지해 자동으로 다시 배포한다.
